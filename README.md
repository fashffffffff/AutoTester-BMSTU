# AutoTester

Расширение для браузеров на Chromium (Brave, Chrome, Edge, Яндекс), которое помогает с тестами в LMS Бауманки: читает вопрос и варианты прямо со страницы, отправляет их в твой чат с DeepSeek-ом и отмечает галочки. Тебе остаётся проверить ответы и закончить попытку.

Работает через твой личный чат с DeepSeek-ом, через вкладку в браузере, а не через апи ключ

## Установка

1. Скачай репозиторий: зелёная кнопка **Code → Download ZIP**, распакуй.
2. Открой `brave://extensions` (в Chrome - `chrome://extensions`).
3. Включи **Режим разработчика** (переключатель справа сверху).
4. Нажми **Загрузить распакованное расширение** и выбери папку `extension`.

## Важно после установки

Расширение подключается к странице только если та загрузилась уже с включённым расширением. Поэтому **обнови вкладку с LMS (F5)** после установки - и вообще делай это после каждого обновления расширения, иначе оно продолжит работать по-старому.

## Как пользоваться

1. Залогинься в LMS и в [deepseek-е](https://chat.deepseek.com) в одном и том же браузере.
2. Открой тест и нажми «Пройти тест»
3. На странице с вопросами нажми иконку AutoTester → кнопку **Решить** (или Alt+S на странице теста).
4. Дальше оно само: отправляет вопросы в DeepSeek, отмечает варианты и листает страницы. Прогресс на плашке справа снизу, а подробный лог в попапе.
5. После последнего вопроса попадёшь на страницу предпросмотра. **Проверь ответы глазами и закончи попытку сам** - финальную кнопку расширение по умолчанию не нажимает(я думаю разберетесь где можно включить, если хотите).

Кнопку «Решить» жмёшь один раз на попытку, не на каждом вопросе, а на каждом новом тесте

## Настройки

Иконка → «Настройки»:

- **Сам нажимать финальную «Закончить попытку»** — по умолчанию выключено. Включишь — будет сдавать попытку целиком без тебя.
- **Строгий режим** — если DeepSeek ответил совсем непонятно, расширение остановится, а не пропустит вопрос.

## Что важно знать

- Вкладку с чатом DeepSeek и вкладку с тестом во время решения не закрывай. Свёрнутое окно - не проблема, расширение нормально работает в фоне.
- Режим «DeepThink» (рассуждения) в DeepSeek лучше держать выключенным: с ним ответы дольше и хуже распознаются.
- Вопросы, где надо вписать текст или сопоставить строки, расширение пропускает — добиваешь руками.
- Если что-то пошло не так, красная плашка на странице покажет причину, а подробный лог - в попапе расширения.
